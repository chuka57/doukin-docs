今回、忘れないこと

必須の条件
会社アカウントは使いません。登録・ログイン・復旧・開発運用も対象です。
優先して探す方法
個人メール以外の方法を優先。個人メールや個人OAuthは、許容できる場合の代替案として比較します。
費用の考え方
原則無料。月額0円と、支払情報の登録・超過課金のある無料枠を区別します。
まだ仮定の部分
数十人の利用・開発者約3人を想定。写真・体重・PWAなどのMVP範囲はIssue #2と相談中です。
