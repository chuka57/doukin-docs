よく出てくる言葉

認証 / 認可
認証は誰かを確かめること。認可は、その人が何をしてよいかを判断すること。
パスキー / RP ID
端末側の認証操作と公開鍵を使うログイン手段。RP IDはどのサービス向けの資格情報かを区別するドメイン識別子。
OAuth
外部サービスの認証連携で使われる仕組み。今回は個人の認証サービスを利用するログイン案として扱います。
RLS / Security Rules
DBやサービス側でデータの読書きを制御する機能。UIで表示を隠すだけの処理とは別です。
JWT / セッション
ログイン状態を示す情報や仕組み。署名の確認、期限、失効の反映、会員状態の確認が必要です。
MAU / MRU
MAUは月間アクティブユーザー。ClerkのMRUは登録後に戻ってくるユーザーの独自指標。料金比較で同じ数え方と見なさないでね。
CPU / 経過時間
CPUは処理に使う時間。通信を待つ時間を含む、操作全体の経過時間とは異なります。
走査行 / 返却行
DBが探すために読んだ行と、利用者へ返した行。20件返すだけでも、全件を走査している場合があります。
GB / GiB
十進と二進の容量単位。概算はMB/GB、Firestoreの公式枠はGiB表記を維持しています。
SMTP / DNS
SMTPはメールを送る仕組み。DNSはドメインの接続先などを管理する設定。送信ドメインの確認にも使います。
PITR / Time Travel
ある時点へデータを戻す仕組み。対象期間・プラン・戻せるデータはサービスごとに異なります。
PWA / SSR
PWAはWebアプリをインストール等に対応させる仕組み。SSRはサーバーで画面のHTMLを生成する方式。本資料では利用する場合・省く場合を比較し、要件の確定状況は記載しません。
