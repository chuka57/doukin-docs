# MVP機能提案からの引き継ぎ

[提案資料](../docs/proposal-mvp.html)の前提と、実装前に相談する項目をまとめます。

| テーマ | 提案の前提 | 相談する項目 |
| --- | --- | --- |
| 参加・認証 | 本人と、記録を閲覧できる同期を識別する | [参加・認証の仕様例](../docs/proposal-auth.html)、招待・失効・復旧 |
| 簡易記録 | ホームで「自分だけに記録」「同期に共有して記録」のいずれかを押すと今日の1件を保存。詳細入力は別の入口 | 日付境界・再試行・連打、非公開の存在や件数、保存後の公開変更 |
| 詳細・再利用 | 種目ごとに複数のセット。重量・回数は任意、セット数は件数。履歴や名前付きテンプレートから種目・セット・メモをコピーし、日付・公開状態・応援は引き継がない | 数値の範囲・単位、種目候補、未来日 |
| 閲覧・応援 | 共有記録を新しい順に表示。👍・👀・💪 は1人1記録につき各種類1回で、個別に取り消せる | 並び順の日付と同日の順序、自分への応援、編集・共有解除・削除・資格失効後の扱い |
| プロフィール・体重 | 表示名、任意の自己紹介・目標・プリセットアイコン。測定日と体重はトレーニングと独立して保存 | 目標の形式、各項目と体重の公開範囲、同日複数測定、訂正・削除・保持期間 |
| PWA・通知 | 初期版はホーム画面からの起動、受けた応援は記録上で確認。新着一覧・既読、端末への通知、オフライン保存は後続候補 | 応援に気づくまでの時間が問題か。端末配信を試すなら許可・購読解除・失効、iOS・Android実機での配信 |
| 運用 | 保存に失敗したら入力を保持し、再試行を案内 | 二重登録対策、退会、バックアップ・復元、ログ、保存製品・費用 |

工数表は基礎機能がそろった場合の概算です。画面は架空の表示例で、アプリの動作確認は試作後に行います。
