# MVP機能提案から他テーマへの引き継ぎ

提案の補足です。提案本文は [原稿](proposal-mvp.html) と [生成ページ](../docs/proposal-mvp.html) を参照してください。

| 引き継ぎ先 | この提案で置く前提・仮定 | 相談が必要な事項 |
| --- | --- | --- |
| 利用対象・認証 | 利用資格があり、本人を識別できる人が使う | 対象者、招待・失効・復旧、認証方式、初回の必須情報。プロフィールの表示名だけで認証できるという意味ではない |
| 公開範囲 | 記録全体を共有／非公開にし、保存時に本人が選ぶ。非公開の存在を同期に見せない画面例 | 共有先、既定操作、存在や件数の表示、保存後の公開変更、一覧・直接参照・集計での一貫した扱い |
| 編集・削除と応援 | 自分のトレーニング記録を編集・削除できる。応援は1種類・1人1記録1回・取り消し可能 | 編集前の応援を保持するか、共有解除・削除後の応援と件数、訂正表示、自分への応援、利用資格失効時の扱い |
| プロフィール・体重 | 表示名、任意の自己紹介・目標。体重入力と測定履歴。体重は本人のみという画面例で、トレーニング共有と別管理 | 各項目・体重の公開単位、初期値、変更方法、体重の訂正・削除、同日複数測定、保持期間 |
| 入力・閲覧の詳細 | 今日を初期表示。種目・重量・回数・セット・メモは任意。履歴・テンプレートは新規入力にコピーする | 日付境界・タイムゾーン、未来日、数値範囲・精度・単位、セット別入力、種目候補、一覧の並び・表示件数。日付・公開状態・応援はコピーしない案 |
| データ運用・基盤 | 所有者・閲覧権限を確認。保存失敗時は入力を保持する画面案 | 二重登録対策、退会・削除、バックアップ・復元、ログ、保存製品、費用、物理データ設計 |

## 機能提案として含めたい範囲

簡易記録、任意の詳細入力、後からの詳細追記、自分のトレーニング記録の編集・削除、履歴コピー、名前付きテンプレート、共有記録の新しい順の閲覧、応援と取り消し、最小プロフィール、体重入力と履歴確認。

MVP外とする提案：体重・トレーニングのグラフ、アイコン、写真・動画、コメント、通知、カレンダー、ランキング、テンプレートの他人への共有、自動メニュー提案。
