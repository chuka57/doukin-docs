# 参加・認証の仕様例から他テーマへの引き継ぎ

[参加・認証の仕様例](../docs/proposal-auth.html)で想定する条件です。

| テーマ | 確認すること |
| --- | --- |
| 基盤・費用 | 外部認証（OAuth／OIDC）の提供元と仲介サービスの有無。取得属性、DB・ログへの保存、利用上限・課金制限を確認する。 |
| 記録・共有 | 承認済み会員だけが利用できる前提で、データごとの閲覧・更新権限を決める。 |
| 運営・端末 | 管理者による招待と承認、別端末でのログイン、端末ごとのセッションと全端末失効を確認する。 |
| 退会・バックアップ | 退会後に記録やバックアップを削除する範囲と時期を決める。外部アカウントを復旧できない場合のデータの扱いも検討する。 |
